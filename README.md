# MLOps CI/CD Pipeline

A beginner-friendly MLOps project using Python, Streamlit, pytest, and GitHub Actions.

## Features
- Train a machine learning model
- Predict diabetes risk using Streamlit
- Automated testing with pytest
- CI/CD pipeline using GitHub Actions

## Project Structure

```bash
.
├── app.py
├── data/
├── models/
├── src/
├── tests/
├── requirements.txt
└── .github/workflows/
CI/CD

GitHub Actions automatically:

installs dependencies
trains the model
runs tests

whenever code is pushed to the repository.
